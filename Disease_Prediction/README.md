Disease Prediction from Medical Data
About the Project

As part of my Machine Learning learning journey, I developed a Disease Prediction system that analyzes patient medical data and predicts the likelihood of a disease. This project demonstrates how machine learning can be used in healthcare to support early diagnosis and decision-making.

The model is trained on medical data containing various health-related parameters and uses classification algorithms to make predictions.

Project Objective

The main goal of this project is to build a machine learning model that can predict whether a patient is likely to have a disease based on their medical information.

Dataset

For this project, I used a medical dataset containing patient health records. The dataset includes features such as:

Pregnancies
Glucose Level
Blood Pressure
Skin Thickness
Insulin
BMI
Diabetes Pedigree Function
Age

The target variable indicates whether the patient has the disease or not.
